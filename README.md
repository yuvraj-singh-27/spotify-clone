# 🎵 Spotify Clone

This is a Spotify-inspired website that I built using **HTML and CSS**.

I made this project while learning frontend development. My main goal was to practice creating a real-looking website layout and improve my understanding of CSS, Flexbox, responsive design, hover effects, and page structure.

## 🌐 Live Demo

[View Live Website](YOUR_LIVE_DEMO_LINK)

## 📸 About the Project

The website has a Spotify-style interface with:

- Sidebar navigation
- Search bar
- User profile
- Recently Played section
- Made For You section
- Music cards
- Play button hover effects
- Bottom music player
- Progress bar
- Volume control
- Responsive design

I used my own local images for the music cards to make the website look more realistic.

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- CSS Transitions
- CSS Hover Effects

✨ Features
Music Cards

Different music cards are displayed with an image, title, description, and play button.

Search Bar

A Spotify-style search bar with hover and focus effects.

Music Player

A fixed music player is placed at the bottom of the screen with:

Previous button
Play button
Next button
Progress bar
Volume control
Song information
Responsive Design

I added CSS media queries so the layout adjusts for different screen sizes, including desktop, tablet, and mobile.

Hover Effects

I also added some CSS hover effects to make the website more interactive, such as:

Music card animations
Play button effects
Sidebar link effects
Profile hover effect
Search bar effects
